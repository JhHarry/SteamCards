## 简体中文

SteamCards 是一款面向 Windows 平台的 Steam 库存卡牌估值桌面应用。本版本提供两个发布文件：

### 发布文件

- **SteamCards-1.0.0-win-x64-portable.zip**：便携版，解压后双击 `SteamCards.exe` 即可运行，无需安装。
- **SteamCards-1.0.0-win-x64.msi**：MSI 安装包，支持安装选项（是否创建桌面快捷方式、安装完成后是否启动），卸载时可选择是否删除用户数据。

### 功能概览

- 读取 Steam 公开库存中的集换式卡牌并进行估值
- 优先使用精确价格接口，限流时自动切换市场搜索接口批量补价
- 本地价格缓存、库存缓存与历史估值记录
- 导出卡牌明细 CSV 与汇总 CSV
- 中英文界面，按系统语言自动切换

### 系统要求

- Windows 10 / 11 x64
- WebView2 Runtime（Windows 10/11 通常已预装；缺失时请安装微软 WebView2 Runtime）
- 使用系统自带 WebView2，不额外捆绑运行时

## English

SteamCards is a desktop application for valuing the trading cards in a Steam inventory, built for Windows. This release ships two files:

### Release files

- **SteamCards-1.0.0-win-x64-portable.zip**: Portable build. Unzip it and double-click `SteamCards.exe` — no installation required.
- **SteamCards-1.0.0-win-x64.msi**: MSI installer with setup options (create a desktop shortcut, launch after installation). During uninstall you can choose whether to remove your user data.

### Features

- Reads tradable cards from a public Steam inventory and values them
- Uses the exact price endpoint first, automatically switching to the market search endpoint for bulk price filling when rate limited
- Local price cache, inventory cache and valuation history
- Exports both a per-card CSV and a summary CSV
- Chinese and English UI, switched automatically based on the system language

### Requirements

- Windows 10 / 11 x64
- WebView2 Runtime (usually preinstalled on Windows 10/11; install Microsoft's WebView2 Runtime if missing)
- Uses the system-provided WebView2 — no runtime is bundled
